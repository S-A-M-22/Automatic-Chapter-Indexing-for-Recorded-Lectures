AutoChapter — Visual Sliding-Window Pipeline

6-stage chapter segmentation: visual boundary detection + NLP + LLM labelling

🎵
1 / 6

Audio Extraction

Extract single-channel 16 kHz WAV audio from the uploaded video file using FFmpeg.

FFmpeg 16 kHz mono {stem}.wav
▾
🎙
2 / 6

Speech-to-Text (Whisper ASR)

Transcribe the audio into timed text segments using OpenAI Whisper. Filler words are cleaned. Output is saved as a plain-text transcript file.

Whisper large-v3-turbo language=en {stem}_transcript.txt
▾
👁
3 / 6

Visual Feature Extraction + Boundary Detection

Sample video frames at fixed intervals and extract 512-d feature vectors via ResNet-18 (classification head removed). Build overlapping sliding windows, compute inter-window cosine distance, smooth with a Gaussian kernel, and detect peaks as visual scene-change boundaries.

ResNet-18 (ImageNet) frame every 15s W=60s S=5s σ=2.0 scipy find_peaks prominence≥0.05
▾
📝
4 / 6

Transcript Slicing + SBERT + KeyBERT

Slice Whisper segments at the visual breakpoints to form chapter-length text blocks. Merge any chapter shorter than 60 words into its neighbour. Encode chapter text with SBERT and extract the top 5 keywords per chapter via KeyBERT. Save the resulting chapter features as raw_chapter.json.

all-MiniLM-L6-v2 KeyBERT min 60 words top_n=5 keywords raw_chapter.json
▾
🧠
5 / 6

LLM Chapter Labelling + Classification

Feed each chapter's transcript, timestamps, and word count to Qwen 2.5-1.5B-Instruct. The LLM generates a 5–8 word title and a 1–2 sentence description per chapter. A keyword heuristic then classifies each chapter as key or skip (low-value). Up to 3 retries with JSON brace extraction for robustness.

Qwen2.5-1.5B-Instruct CPU float32 temp=0.1 max 3 retries
▾
💾
6 / 6

Save Final Chapters

Write the labelled chapter index as a JSON array. Each entry contains: ID, title, description, start/end timestamps, key/skip classification, 5 keywords, and the boundary source tag.

{stem}-chapters.json
